00 · The challenge

Sales have a system. Inventory has a clipboard.

Sales leadership wanted to track this client like the others: sell-out in units and value, inventory, and the two combined. The extract from the client's system carried the sales, but the inventory position of our products in the stores came from manual counts done in the stores and recorded in one-off spreadsheets, each in a different format.

Without a standard count, there is no comparing stores or dates. The problem started before the dashboard: at the blank spreadsheet.

01 · Two sources, one dashboard

The technical base of the sell-out dashboards, with a new inventory source.

The project starts from the same architecture as the Vitta Dashboard: import with precomputed fields, caching, undo by batch, history, and users with roles. The difference is inventory, which got its own collection, import, validation and template.

SALES

Client's system

Raw sales data by store and product, with a reference month when the file is monthly. Feeds the sales tabs.

INVENTORY

In-store counts

A standardized spreadsheet with count date, branch, product, EAN and quantity. The dashboard always shows the most recent count.

04 · A self-building spreadsheet

The count template is built from current data.

The template button doesn't hand out a generic blank spreadsheet. It builds the count from what the dashboard already knows:

ROWS

Every store × every product

Stores come from the store mapping and products from the category mapping. Nobody forgets an item or types the wrong EAN.

QUANTITY

The last count as a starting point

If a count already exists, the template comes with the quantity from the most recent date. With no history, the column stays blank.

AVAILABLE

Works even while the database starts up

If the database is still coming up or generation fails, the server delivers a base template stored with the application.

CLEAN

Only the right columns

Import templates come out without the columns the dashboard calculates, so the file comes back in exactly the expected format.

06 · Front end

The usual tabs, with counted inventory.

The interface follows the family of sell-out dashboards (Sell-Out Sales, Sales Value, Sales by Day, Inventory, Sell-Out × Inventory, Import and Manage Users). The filters were refined here: select all options at once, check and uncheck everything, and keep the monthly chart when filtering a store.
